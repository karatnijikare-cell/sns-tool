ニジカレ SNS投稿ツール プライバシーポリシー

制定日: 2026年10月15日 ／ 運営者: 株式会社カラット

株式会社カラット（以下「当社」）は、当社が運営するアプリ「ニジカレ」の公式SNSアカウントへ当社の宣伝動画を投稿するための社内ツール「ニジカレ SNS投稿ツール」（以下「本ツール」）における情報の取り扱いを、以下のとおり定めます。

1. 本ツールについて

本ツールは、当社の従業員だけが使う社内ツールです。当社が制作した動画を、当社の公式YouTubeチャンネル等へアップロード・予約投稿するために使います。一般の方への提供・販売はしていません。

2. YouTube API サービスの利用

本ツールは YouTube API サービスを利用しています。本ツールを使うことで、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては Google プライバシー ポリシーをご覧ください。

3. 取得・保存する情報

  • Google の認証情報（OAuth トークン）: 当社のYouTubeチャンネルへ動画をアップロードするために、Google のログイン画面で許可を得て取得します。本ツールを動かすPCの中だけに保存し、外部へ送信しません。Google アカウントのパスワードは取得・保存しません。
  • YouTube チャンネルのID・名前: 投稿先のチャンネルを画面に表示するために取得します。
  • アップロードした動画のID・URL: 投稿結果を確認するために保存します。

視聴者のデータ、コメント、他のチャンネルの情報は取得しません。

4. 利用目的と第三者への提供

上記の情報は、当社の動画をYouTubeへアップロードし、その結果を確認する目的にだけ使います。第三者へ提供・販売しません。本ツールに広告は表示しません。本ツールは Cookie を使用しません。

なお、投稿文の下書きを作る機能では、動画の字幕（当社が作成した台詞のテキスト）を OpenAI の API に送信します。この送信に YouTube から取得した情報は含まれません。

5. 保存期間と削除

  • 本ツールの「連携を解除」を押すと、Google 側の許可を直ちに取り消し、PCに保存した認証情報と、YouTube から取得した情報（チャンネル名・動画のURL等）を削除します。
  • Google アカウントのセキュリティ設定ページからも、本ツールへの許可をいつでも取り消せます。この方法で取り消された場合、当社は保存している YouTube から取得した情報を 30 日以内に削除します。
  • 本ツールで情報を削除しても、YouTube に投稿済みの動画は削除されません。動画の削除は YouTube Studio から行ってください。

6. お問い合わせ

本ポリシーに関するお問い合わせ: support@nijikare.jp

7. 改定

本ポリシーを改定する場合は、このページでお知らせします。情報の使い方を変える場合は、本ツールの利用者に改めて同意を求めます。

Nijikare SNS Posting Tool — Privacy Policy

Effective: October 15, 2026 / Operator: 株式会社カラット

株式会社カラット ("we") operates the "Nijikare SNS Posting Tool" (the "Tool"), an internal tool used to upload our own promotional videos to the official social media accounts of our app "Nijikare". This policy explains how the Tool handles information.

1. About the Tool

The Tool is used only by our employees to upload and schedule videos produced by us to our official YouTube channel and other official accounts. It is not offered or sold to the public.

2. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, users agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles information.

3. Information we access, collect and store

  • Google OAuth tokens, obtained with the user's permission through Google's sign-in screen, used to upload videos to our YouTube channel. They are stored only on the computer running the Tool and are never sent elsewhere. We never obtain or store Google account passwords.
  • YouTube channel ID and name, used to show the destination channel in the Tool.
  • IDs and URLs of uploaded videos, stored to confirm upload results.

We do not collect viewer data, comments, or information about other channels.

4. How we use and share information

The information above is used only to upload our videos to YouTube and confirm the results. We do not share or sell it to third parties. The Tool shows no advertising and uses no cookies.

The caption-drafting feature sends the subtitle text of our videos (lines written by us) to the OpenAI API. No data obtained from YouTube is included in that request.

5. Retention and deletion

  • Pressing "連携を解除" (Disconnect) in the Tool immediately revokes the Google authorization and deletes the stored tokens and all data obtained from YouTube (channel name, video URLs, etc.).
  • Users can also revoke the Tool's access at any time via the Google security settings page. In that case we delete stored YouTube API data within 30 days.
  • Deleting data in the Tool does not delete videos already published on YouTube. Use YouTube Studio to delete videos.

6. Contact

Questions about this policy: support@nijikare.jp

7. Changes

We will announce changes on this page and ask users to consent again before using information in new ways.
